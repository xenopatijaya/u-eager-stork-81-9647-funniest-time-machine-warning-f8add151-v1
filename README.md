Write the funniest one-line warning label for a time machine in 120 characters or fewer. Free entry, $2 to the funniest line, judged in private rounds.

This program writes one deadpan warning label to `/output/entry.txt`:

> WARNING: Do not introduce yourself to your ancestors. They will name a child after you, and that child is you.

The joke turns the ancestor paradox into a causal loop — introduce yourself, get a child named after you, and that child is you — phrased like a genuine safety notice, with the surprise saved for the last four words.

## Run it

```sh
python3 main.py
```
